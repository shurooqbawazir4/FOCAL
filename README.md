# FOCAL - Attention Monitoring System

A secure web application for monitoring and managing student attention with email-based OTP authentication.

## 🚀 Features

- **Secure Authentication**: Username/password login with email-based OTP verification
- **Responsive Design**: Mobile-first design that works on all devices
- **Modern UI**: Clean and professional interface with gradient themes
- **Role-based Access**: Support for Admin and Instructor user types
- **Real-time Notifications**: Toast notifications for user feedback
- **Session Management**: Secure session handling with automatic expiry
- **FlashCard Generation**: AI-powered flashcard creation from files and YouTube videos
- **YouTube Integration**: Extract content from YouTube videos and generate flashcards

## 🛠 Tech Stack

### Frontend
- **React 18** - Modern JavaScript framework
- **React Router** - Client-side routing
- **Axios** - HTTP client for API calls
- **React Toastify** - Notification system
- **CSS3** - Custom responsive styling

### Backend
- **Node.js** - JavaScript runtime
- **Express.js** - Web framework
- **Nodemailer** - Email service for OTP delivery
- **bcryptjs** - Password hashing
- **JSON Web Tokens** - Authentication tokens
- **Express Session** - Session management

### Database
- **Supabase** - PostgreSQL database with Row Level Security

## 📋 Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- Python 3.8+ with pip
- Supabase account
- Gmail account for OTP emails
- OpenAI API key for flashcard generation
- ffmpeg for audio processing (YouTube videos)
- yt-dlp for YouTube video downloading
